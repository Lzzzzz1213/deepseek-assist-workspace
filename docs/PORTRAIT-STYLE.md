# 竖屏通讯客户端

用户最新要求：使用自己的 Lanven UI Android / Prism 设计风格，保留已经可用的竖屏 Windows 客户端与聊天交互。

- 页面始终单列。首次打开是群组列表，点击群组进入聊天页，顶部返回按钮回到列表；窗口拉宽也不恢复旧的双栏控制台。
- 同一工作区只有一个持久工作群，任务与不同来源聊天的对话按时间连续显示；任务仍可筛选，不按本轮任务名新建群。
- 列表选中项、引用、导航和通知均不使用左侧装饰色条；选中反馈用完整细边框、柔和背景和焦点环，引用使用整块柔和表面。
- 列表直接显示群名、最后消息摘要和更新时间，不显示字母群头像；聊天头同样不放群头像占位。聊天页保留紧凑顶栏、左右消息气泡、发送者和时间；ChatGPT 任务及主审在右，DeepSeek 公开回复在左。
- 恢复七色识别、青蓝紫主渐变、冷白/靛蓝主题及柔和背景光晕。顶栏为玻璃感浅色/深色表面，列表为克制的圆角卡片或分组行，筛选使用 Lanven 移动分段控件。所有配色来自既有 --lv-* 令牌，禁止在应用层重定义这套公共令牌或保留旧的单蓝/绿色聊天配色。
- 头像、卡片、弹层沿用 9/12/16/22 圆角；消息角色继续采用用户指定头像。菜单、按钮、输入框共用同一套表面、边框和焦点状态。不要添加 KPI、任务侧栏或额外业务模块。
- 两类来源身份必须真实可辨，不伪造联系人、未读数、已读回执或发送功能。群聊仍只观察已授权的协作消息。
- 消息双方显示用户指定的本地图片头像，蓝发为DeepSeek、白发为ChatGPT（含主审），使用64px圆角方形并为气泡预留72px。头像路径只由固定身份映射决定，加载失败保留首字母回退。角色头像为原生按钮，点击或键盘打开资料弹窗，使用128px大图、固定本地趣味介绍与真实分工，沿用原生dialog的焦点和关闭行为。首页页头固定显示48px双角色应用图标，不再显示原聊天气泡图形；列表与聊天页顶部不放装饰彩条，完整卡片边框和焦点环保持。
- 首页名称显示 `DeepSeek协助工作区`。消息头像显式使用1px主题细边框，避免原生按钮的深色outset边；悬停彩色光圈与键盘焦点环保持。角色资料卡移除标题旁的人物装饰图标与顶部彩条，保留关闭按钮、128px角色大头像及完整卡片细边框。
- 搜索和任务筛选按需展开；群详情、导出、删除与主题等操作进入顶部菜单。删除继续原生确认；通知顶部居中。仅保留一条轻量同步状态，不堆放说明卡片。
- 消息正文和列表内容使用14px、行高1.6；Markdown标题依次18/16/14/13px，表格13px、代码12px，代码恒暗。超过400字的消息默认折叠为160px预览，展开/收起、Markdown全文解析、原文复制/导出与安全DOM规则保持。图标操作命中区48px，输入框参考56px；这些CSS尺寸用于Windows上的移动派生视觉，不宣称Android原生dp/sp验收。宽表格和代码局部滚动。
- 展开入口采用30px的紧凑文字按钮与方向箭头，悬停用柔和表面，保留键盘焦点环与aria-expanded。切换只改变已有气泡的高度类和按钮状态，不重建消息/头像、不重复解析Markdown；角色头像靠消息顶部，视口由当前消息局部维护。
- 大群采用可变高度虚拟列表，仅挂载视口及400px缓冲；滚出后回收DOM，缓存按窗口限制，48/64为可见行优先的软目标。展开和宽度变化保留长文锚点，底部跟随时高度变化继续显示最新消息。折叠正文只生成有界预览DOM，共用完整Markdown解析缓存，原文搜索/复制/导出保持完整；不把CSS隐藏全量DOM当成懒加载。
- 原生窗口客户区恢复约420×780逻辑像素，按本机DPI和屏幕可用区调整；最小约340×560。使用Windows原生标题栏、系统默认高度与窗口按钮，保留拖动、边缘缩放、关闭到托盘、置顶和真实退出功能，不改变Windows全局标题栏设置。
- 用户撤回加高标题栏方案，移除自定义标题控件、非客户区覆写和标题主题桥接；标题栏外观由Windows管理，网页明暗主题与其他界面调整保持。宿主恢复禁用WebMessage，不提供命令、文件或其他宿主接口；Host对象、导航、资源和权限限制保持。
- 用户要求整体更小：Windows WebView2 统一使用 85% 显示比例，字体、头像、控件和留白同比例缩小。上述 CSS 基准与 Prism 配色保持，不单独重设公共令牌。

视觉依据：已安装的 `lanven-ui-android` 技能及本项目 `docs/ANDROID-STYLE.md`、`web/vendor/lanven-ui.tokens.css`。仅迁移视觉，不迁移为 Android 工程，不改变真实记录与权限边界。

窗口实现采用WinForms默认系统外壳，不再使用DWM自定义窗口框架。
