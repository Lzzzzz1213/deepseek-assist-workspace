# OpenAI 相关设计边界

更新日期：2026-10-21。以下记录本工具采用的公开接口与安全措施，不是官方认证或所有场景下的合规证明。

1. **使用公开的事件接口。** 观察入口读取 `codex exec --json` 的类型化 JSONL；只选择明确的任务、公开 `agent_message` 与调用生命周期。记录器拒绝 `reasoning`、系统/开发者提示、原始网络请求与原始工具正文。
2. **权限与观察分离。** 工作观察不能从页面发起Agent任务、修改项目文件或扩大既有权限。用户明确开启的独立私聊只能请求无工具权限的普通模型回复。原辅助入口的文件清单、最新哈希、并发锁、独立配置、主智能体审查保持生效。
3. **不可信内容只作数据。** 事件经过固定字段白名单；消息作为文本显示，不执行 HTML、脚本或内容中的工具指令。按用户选择，工具操作不显示、不参与消息计数、搜索或导出；原 helper 的执行审计仍独立保留。
4. **减少凭据和数据暴露。** API 密钥不进入浏览器或记录器；任务和公开消息写入前、API 返回前过滤常见密钥、Bearer、密码与私钥格式。私聊会在用户发送时向DeepSeek传输当前消息、相关本地记忆和有界公开工作摘要，界面已注明；不读取其他Codex聊天的私有历史。脱敏并不代替项目对原始材料的检查。
5. **明确来源和真实状态。** Codex / ChatGPT 与 DeepSeek 分别标明；“调用成功”不表示业务验证或主审通过。界面使用本项目名称，不使用 OpenAI 官方认证标志。记录保存在本机，可导出；用户确认后的删除仅保存客户端隐藏标记，原始事件记录、项目源码和 Codex 文件始终只读。

公开来源：

- [Codex 非交互模式：JSONL 事件、最小权限与认证](https://learn.chatgpt.com/docs/non-interactive-mode)
- [OpenAI Agent 安全建议：不可信数据、结构化数据流和私密信息保护](https://developers.openai.com/api/docs/guides/agent-builder-safety)
- [OpenAI API 数据控制说明](https://developers.openai.com/api/docs/guides/your-data)

API 数据控制说明针对 OpenAI 服务；本工具的本机记录和 DeepSeek 服务是各自独立的数据处理范围。本工具不声称改变任何服务商的数据保留政策。

Windows 客户端使用 WebView2 的独立本机配置，禁止外部导航、新窗口、相机麦克风权限、开发者工具和任意主机对象。内置服务仅监听回环地址；退出时只清理本次客户端自行启动的服务进程，不会停止其他任务的模型执行。

独立私聊的角色设定不覆盖任务边界；清空聊天保留本地记忆不等于删除隐私档案。表情只用有固定出处的本地白名单，来源说明见 PRIVATE-CHAT.md 与位图目录sources.json。
