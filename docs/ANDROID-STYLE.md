# Lanven UI·Android 通用应用设计指南

版本：扩展稿 0.1.0（常规安卓应用；样式与交互均为本地示例，未做真机或无障碍验证）。
适用：任意个人 Android 应用（内容、工具、记录、生活等），不限于 Lanven Shell 运维领域。
入口：[index.html](./index.html)（20 组补充组件）与 [demo.html](./demo.html)（10 页可点击模板）。
依据：[Android 设计审核稿指南](../docs/ANDROID_GUIDE.md)、`shared/lanven-ui.tokens.css`（设计来源，不在本目录复刻）。
既有 32 组件与 11 个运维页面是参考资产，不重新设计；Prism 基线不变。
优先级：产品 / 客户规范与当次用户选择高于本文规则。

## 1. 视觉基线
- 主色青蓝紫渐变，七色光谱作品牌识别；冷白与靛蓝双主题，取值走 `--lv-*` / `--la-*` 变量。
- 圆角集合 9 / 12 / 16 / 22，间距取 4 的倍数。
- 内联卡片用 12、主容器用 16、底部 sheet 顶角用 22；头像、胶囊等沿用已有专用形状，避免随机新增圆角。

## 2. 移动派生尺寸（派生值，不照搬桌面小控件）
| 项目 | 值 | 说明 |
| --- | --- | --- |
| 最小触区 | 48dp | 图标按钮、导航项命中区不小于 48dp |
| 控件高度 | 48 / 56dp | 主按钮 48dp，单行文本框 56dp |
| 字阶 | 16 / 14 / 12sp | 正文 16sp、辅助 14sp、小标签 12sp，随系统字体缩放 |
- 顶栏 56dp、底部导航 64dp，均另加系统栏与刘海 Inset。
- HTML 的 CSS px 只模拟外观，不能作为真机密度、字体缩放与 Insets 的证据。

## 3. 页面结构与导航
- 通用页面族：首页、列表、详情、搜索与筛选、创建 / 编辑、消息、我的、设置、登录、引导。
- 示例页名统一为「Lanven Daily · 通用应用示例」，仅作模板，无产品接入。
- 主导航按项目选少量顶级目的地；不固化 Shell 四项、不设根页双返回、不引入运维领域概念。
- 手机按目的地选择底部导航等已有模式，局部选项用底部 sheet；目的地较多时分组或沿用项目已有导航。

## 4. 平板 / 横屏
- 按窗口宽度（WindowSizeClass）选择：窄用底部导航，宽用 NavigationRail。
- 宽屏用双栏（列表-详情、会话-详情并列），不把手机单列布局硬拉伸。

## 5. 交互与返回
- 返回优先级：先收输入法 / 收起弹层 / 关闭选择器，再按页面层级返回。
- 根页面退出遵循项目与平台约定，不为统一风格更改退出策略。
- 表单含校验、草稿与「未保存离开确认」；权限被拒后提供替代路径（见 COMPONENTS #17、#18）。

## 6. 数据与状态
- 覆盖离线 / 空态 / 分页 / 下拉刷新；离线与缓存命中只陈述事实，不伪造成功。
- 所有示例交互均为本地演示：无网络请求、无业务写入，不声称真实业务成功。

## 7. 权限与系统能力
- 运行时权限在上下文处询问并说明用途；拒绝后给出可用替代路径。
- 通知开关只反映应用内偏好，不伪造也不代替系统授权状态。
- 日期 / 时间 / 文件 / 照片选择复用系统原生选择器，通知由系统接管，本稿只演示样式。

## 8. 可访问性与平台能力
- 触区 48dp、正文 16sp 起；支持字体缩放与边到边 Insets，避免固定高度截断文本。
- TalkBack：语义标签、状态播报、可聚焦分组；纯装饰图给空描述。
- 复用 Compose 无障碍默认值，不自造语义或用颜色单独承载信息。

## 9. 与现有实现映射
- 默认 Kotlin / Compose，可映射既有 XML / Views，不为风格迁移更换技术栈。
- 顶栏 / 底栏 / Insets / 返回层级沿用既有结构（见 ANDROID_GUIDE §6），本稿不替换。

## 10. 范围
- 本文只维护可复用规则与清单；组件用法、状态与复用见 [COMPONENTS.md](./COMPONENTS.md)。
- 本目录是样式与交互参考；实际开发按当次授权接入业务，沿用技术栈，并执行项目要求的检查。
