# Lanven UI·岚枫云 设计规范

> 本项目当前使用用户的 Lanven UI Android / Prism 外观，保留竖屏 Windows 客户端。颜色沿用本文公共令牌，移动字号与触区、卡片层次按 `ANDROID-STYLE.md`，单列导航及聊天布局按 `PORTRAIT-STYLE.md`。

版本 0.1.0（基础样式包 + 文档，非已发布服务）。风格基线为用户已认可的 Prism：
本规范只固化既有视觉，不自由更换配色。变量命名空间 `--lv-*`，类名 `.lv-*`，
HTML 需 `data-lv-theme="light|dark"`，容器或 body 需 `data-lv-ui`。

## 1. 设计原则
- 稳妥优先：沿用已认可视觉，宁可少改，不做无声换色。
- 一次定义、多项目复用：同一套 tokens 服务文档站与个人项目。
- 克制反馈：只反馈真实状态，不伪装成功、不夸大进度。
- 层级一致：同一语义始终用同一颜色、圆角与尺度。
- 中文优先：中文系统字体为主，技术内容用等宽。

## 2. 色彩
- 七色光谱为品牌骨架；主按钮为青蓝紫（默认 primary）。
- 语义变体：柔和 soft、AI 紫、枫橙、危险 danger。变体只用于强调与状态，
  不替换主干色，也不作为唯一区分手段。
- 冷白与靛蓝双主题：全部通过 `--lv-*` 变量取值，组件内不硬编码颜色。
- 背景光晕只做氛围层，不承载信息，其上文字仍须可读。
- 低优先色（弱文本、禁用、分隔、光晕上的次要文字）对比度需逐个核对；
  本规范不宣称整站通过 WCAG 认证。
- 终端区域恒暗，不随主题翻白。
- Cloud现有品牌蓝 `#2E5CF6` 属来源与兼容信息，不覆盖本次确认的Prism默认色。

### 2.1 禁止左侧装饰色条

- 页面和组件左侧不用装饰性纯色色块、竖条、彩色粗边或单侧内阴影，包含列表/表格选中项、导航、引用、提示和弹窗。
- 强调使用整块柔和背景、完整细边框、图标和文字；选中状态与键盘焦点仍须可辨识。
- 本项目 vendor 样式副本的选中行、导航、引用已按此规则局部修正；不改全局技能和其他项目。
- 头像、状态圆点、结构分隔线、均匀边框及顶部光谱识别不属于左侧装饰竖条。

## 3. 字阶与字体
- 基准14px；沿用12 / 13 / 14 / 16 / 18 / 22 / 28 / 36 / 44的令牌字阶，
  不把原稿较丰富的标题层次改成另一套字号体系。
- 中文用系统字体栈，技术内容（代码、路径、日志、终端）用等宽。
- 行高：正文约1.6，标题约1.3；正文、控件与标题按层级使用字重，保留原稿标题的750–900强调。

## 4. 空间、圆角与控件尺度
- 圆角集合固定为 9 / 12 / 16 / 22，不新增随意值：小控件用小值，卡片与容器用大值。
- 控件高度集合固定为 24 / 30 / 36 / 44，同一行内高度保持一致。
- 间距取 4 的倍数；区块间距大于元素间距。

## 5. 状态
- 覆盖默认、悬停、聚焦、激活、禁用、加载、危险；每态可辨识。
- 聚焦态必须可见（含键盘导航），禁用态不响应指针语义。
- 加载不阻塞全局；危险操作需二次确认。

## 6. 布局
- 文档站：左目录 + 右内容 + 锚点；组件页含用法 / 实例 / 代码 / API。
- 应用：顶部或侧边导航 + 内容区；终端面板可与内容区并列且恒暗。

## 7. 反馈
- 普通编辑与危险确认使用对话框；需持续上下文辅助的面板使用抽屉。
- 轻提示用消息/通知，不常驻；不伪造操作结果。
- 终端不提供底部 Esc / Tab / Ctrl / 复制 / 粘贴 / 全屏工具条（已明确删除）。

## 8. 可达性
- 禁止只用颜色区分状态，需配文本或图标。
- 键盘可达：Tab 顺序合理、焦点可见、Esc 可按语义关闭对话框或抽屉。
- 对比度只对已核对组合声明达标，其余标注"待核对"。
- 动效尊重 `prefers-reduced-motion`。

## 9. 页面组合约定
- 结构：页头（标题 + 副标题）→ 实例 → 代码 → API → 相关链接。
- 只引用 `dist/lanven-ui.tokens.css`、`dist/lanven-ui.css`、
  `dist/lanven-ui.js`、`dist/icons.svg`。
- DOM 约定：容器 `data-lv-ui`，按钮 `class="lv-btn lv-btn-primary"`。
- 主题跟随系统为默认，应用可按自身主题状态设置 `data-lv-theme`。

## 10. 给后续 AI / 开发者的约定
- 改样式前先读本文件；不自由换配色，不改圆角与控件尺度集合。
- 需要新 token 先讨论登记，禁止就地硬编码。
- 不宣称未经验证的 WCAG 达标或业务成功。
